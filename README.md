# Homework 14.1-17.1

## Описание проекта
Большая часть разработки использует ООП-подход для создания своих сервисов,
а также работы с данными, которые представляют собой сущности или объекты
со своими параметрами и методами. В рамках этих домашних заданий мы проработаем
использование классов и объектов на основе популярной темы e-commerce.

E-commerce — электронная торговля, или электронная коммерция. На данном этапе
работы мы не будем реализовывать систему платежей, однако подготовим всё для того,
чтобы у нас появилось ядро для интернет-магазина. В дальнейшем для этого ядра
возможно будет реализовать любой интерфейс — от сайта до телеграм-бота.

## Требования к окружению:

```
Python 3.13+
```

## Установка:
1. Клонируйте репозиторий:
```
git clone https://github.com/Svetlana062/OOP_homework.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
3. В случае отсутствия менеджера проектов _poetry_, выполните установку пакетов:
```
poetry install
```
4. Войдите в виртуальное окружение:
```
poetry shell
```

## Тестирование
Набор тестов находится в пакете tests.
Чтобы начать тестирование, необходимо, через терминал, установить pytest:
```
poetry add --group dev pytest
```

## Структура проекта

В модулях созданы описания основных сущностей и инициализации объектов:
* category.py - в данном модуле создан класс Category и присвоены атрибуты (name, 
description, products);
* lawn_grass.py - в данном модуле создан класс наследник класса Product: LawnGrass 
(«Трава газонная») и присвоены атрибуты (country, germination_period);
* product.py - в данном модуле создан класс Product и присвоены атрибуты (name, 
description, price, quantity, color);
* product_iterator.py - в данном модуле создан вспомогательный класс, с помощью которого 
можно перебирать товары одной категории;
* smartphone.py - в данном модуле создан класс наследник класса 
Product: Smartphone («Смартфон») и присвоены атрибуты (efficiency, model, memory);
* utils.py - в данном модуле реализована подгрузка данных по категориям и товарам из
файла JSON. Для этого создана специальная функция, которая будет читать файл и создавать
объекты классов.
